GOVERNANCE, RISK MANAGEMENT & AUDITABILITY

Multi-Layered Safeguards Against Failure Modes

🔒

Prompt Injection Sandboxing

Inbound text is escaped (<, >) and wrapped in XML boundaries (<ticket_body>). System prompt strictly forbids executing instructions inside tags.

🧼

Dual-Stage PII Scrubbing

Regex matching and Luhn checksum validation scrub credit cards, phone numbers, emails, Bearer tokens, and CloudServe API keys pre-ingestion and post-generation.

📜

Append-Only SQLite Ledger

Every single decision logs to decision_log.db in WAL mode. Database triggers reject direct UPDATE and DELETE operations, guaranteeing tamper-proof audit trails.

🛠

Zero-Crash Graceful Degradation

Wrapped with @safe_node exception containment and 3-tier cascade. An external outage never brings down the orchestrator process.
